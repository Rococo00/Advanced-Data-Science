Calcolare i punti per ogni giocatore

La funzione sarà definita in 3 ‘blocchi’

compute_points = function(data){

white_wins = data |>
  group_by(White) |>
  summarise(
    Points = sum(Score == 1) + sum(Score==0.5)*0.5
  )


black_wins = data |>
  group_by(Black) |>
  summarise(
    Points = sum(Score == 0) + sum(Score==0.5)*0.5
  )



total = white_wins |>
  full_join(black_wins, join_by(White == Black)) |>
  mutate(Points = replace_na(Points.x,0) + replace_na(Points.y,0) )|>
  rename(Player = White) |>
  select(Player, Points)|>
  arrange(-Points)
}
points = compute_points(data)

Elo somma zero e Funzione Elo

calcolo intanto la funzione per calcolare Elo

compute_elo = function(data, zeta = 400, kappa = 25) {

  players = unique(c(data$White, data$Black))
  ratings = rep(0, length(players))

  white_index = match(data$White, players)
  black_index = match(data$Black, players)

  for (game in seq_len(nrow(data))) {

    i = white_index[game]
    j = black_index[game]

    expected = 1 / (
      1 + 10 ^ ((ratings[j] - ratings[i]) / zeta)
    )

    change = kappa * (data$Score[game] - expected)

    ratings[i] = ratings[i] + change
    ratings[j] = ratings[j] - change
  }

  total = tibble(
    Player = players,
    Elo = ratings
  ) |>
    arrange(desc(Elo))

  return(total)
}

se sommo tutti gli elo, ottengo un valore prossimo allo zero. (probabilmente dovuto a qualche approssimazione) però possiamo confermare che effettivamente è un gioco a somma zero.

elo = compute_elo(data)

Disegnando l’istogramma dei punteggi, possiamo notare come la distribuzione sia leggermente assimetrica. Ci sono più giocatori con Elo <= 0 rispetto a quelli con Elo elevato. Questo può significare la presenza di molti giocatori scarsi / mediocri e pochi giocatori bravissimi. è diversa dalla distribuzione dei punti, perchè qui giocando si può perdere Elo mentre nel grafico di prima, uno giocatore poteva solamente aumentare il proprio punteggio, giocando il più possibile.

Il numero di partite giocate influenza il punteggio?

Il numero di partite giocate, sembrerebbe influire il numero punti. Questo però è banale, dal momento che i giocatori non possono perdere punti giocando, ma ad ogni partita possono ottenere +0, +0.5 o +1 punti. Quindi c’è un grosso incentivo nel giocare il più possibile.

data2 = data |>
  count(White) |>
  full_join(
    data |> count(Black),
    join_by(White == Black)
  ) |>
  mutate(
    Games = replace_na(n.x, 0) + replace_na(n.y, 0)
  ) |>
  select(Player = White, Games) |>
  full_join(ratings, join_by(Player)) |>
  arrange(desc(Elo))

ggplot(data2, aes(x = Games, y = Points)) +
  geom_point(alpha = 0.3) +
  labs(
    title ="Partite giocate influenzano i punti",
    x = "Partite giocate",
    y = "Punti"
  )

Dal grafico direi che chi ha giocato più partite tende ad avere un Elo più alto, ma il numero di partite non basta a determinare il rating.

  • Con poche partite, molti giocatori hanno un Elo vicino a zero. Perché tutti partono da zero e hanno avuto poche occasioni per allontanarsene.

-La curva blu cresce e poi si appiattisce, indicativamente oltre le 200 partite. In quella zona, però, ci sono pochi giocatori: non interpreterei la lieve discesa finale come prova che giocare troppo faccia diminuire l’Elo.
