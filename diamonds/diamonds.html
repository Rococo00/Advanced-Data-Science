2. Modello

Usiamo tutti i diamanti del dataset e passiamo al logaritmo in base 2 di prezzo e carati, perché in scala logaritmica la relazione diventa lineare.

diamonds2 = diamonds |>
  mutate(lprice = log2(price), lcarat = log2(carat))

ggplot(data = diamonds2) +
  geom_point(mapping = aes(x = lcarat, y = lprice), alpha = 0.05) +
  labs(x = "log2(carati)", y = "log2(prezzo)") +
  theme_classic()

mod_carat = lm(lprice ~ lcarat, data = diamonds2)

mod_carat$coefficients
## (Intercept)      lcarat 
##   12.188841    1.675817
summary(mod_carat)$r.squared
## [1] 0.9329893

Il peso da solo spiega circa il 93% della variabilità del (log) prezzo.

ggplot(data = diamonds2, mapping = aes(x = lcarat, y = lprice)) +
  geom_point(alpha = 0.05) +
  geom_smooth(method = "lm", se = FALSE, colour = "red") +
  labs(x = "log2(carati)", y = "log2(prezzo)") +
  theme_classic()

I residui dicono quanto un diamante costa in più o in meno rispetto a quanto ci si aspetterebbe dal suo peso. Poiché sono in scala log2, un residuo di +1 significa che il diamante costa il doppio del previsto, -1 la metà.

diamonds2 = diamonds2 |>
  add_residuals(mod_carat, "lresid")

ggplot(data = diamonds2) +
  geom_point(mapping = aes(x = lcarat, y = lresid), alpha = 0.05) +
  labs(x = "log2(carati)", y = "Residuo") +
  theme_classic()

Il pattern forte del peso è stato rimosso. Ora rifacciamo i grafici iniziali usando i residui al posto del prezzo:

ggplot(data = diamonds2) +
  geom_boxplot(mapping = aes(x = cut, y = lresid)) +
  labs(x = "Taglio", y = "Residuo (log2)") +
  theme_classic()

ggplot(data = diamonds2) +
  geom_boxplot(mapping = aes(x = color, y = lresid)) +
  labs(x = "Colore (Qualità decrescente)", y = "Residuo (log2)") +
  theme_classic()

ggplot(data = diamonds2) +
  geom_boxplot(mapping = aes(x = clarity, y = lresid)) +
  labs(x = "Purezza (crescente)", y = "Residuo (log2)") +
  theme_classic()
